**2. เทคโนโลยีการกำหนดตำแหน่งด้วยดาวเทียม GNSS**

### เทคโนโลยีการกำหนดตำแหน่งด้วยดาวเทียม GNSS และการปรับแก้ค่า (GNSS Correction): [เกลาจาก *…* · รอตรวจคำ]

#### 1. เทคโนโลยีการกำหนดตำแหน่งด้วยดาวเทียม GNSS

- **GNSS (Global Navigation Satellite System)** คือระบบดาวเทียมนำร่องที่ให้บริการระบุตำแหน่งครอบคลุมทั่วโลก ดาวเทียมส่งสัญญาณให้เครื่องรับนำไปคำนวณพิกัดบนผิวโลก การใช้หลายระบบร่วมกัน (เช่น GPS กับ GLONASS) ช่วยเพิ่มความแม่นยำและการครอบคลุม เช่น ถ้าสัญญาณ GPS ขาดในพื้นที่ที่ถูกบัง ระบบอื่นช่วยได้ [เพิ่มโดย Claude · ที่มา: cartrack.co.th/blog/gnss-khuue-aair]
- **ตัวอย่างระบบ GNSS** (ชื่อระบบและประเทศมาจากเนื้อหาเดิมของไฟล์นี้ที่ถูกแทนที่ ดูไฟล์ในโฟลเดอร์ สำรอง)

| ระบบ | ผู้ดำเนินการ |
|---|---|
| GPS | สหรัฐฯ |
| GLONASS | รัสเซีย |
| Galileo | สหภาพยุโรป |
| BeiDou | จีน |

- **ทำไมต้องมีการปรับแก้ (GNSS Correction)** [เพิ่มโดย Claude · ที่มา: swiftnav.com · ตัวเลขรอตรวจ]
  - สัญญาณจากดาวเทียมมีความคลาดเคลื่อนสะสมจากหลายสาเหตุ ได้แก่
    - **ชั้นบรรยากาศ:** สัญญาณผ่านชั้นไอโอโนสเฟียร์และโทรโพสเฟียร์ จึงช้าลงและหักเห
    - **นาฬิกาดาวเทียม:** นาฬิกาอะตอมบนดาวเทียมเบี่ยงเบนเล็กน้อย กระทบการคำนวณตำแหน่ง
    - **วงโคจรดาวเทียม:** ดาวเทียมโคจรเบี่ยงจากเส้นทางที่คาดไว้เล็กน้อย
    - **สัญญาณสะท้อน (Multipath):** เครื่องรับได้สัญญาณเดียวกันหลายสำเนาเมื่อสะท้อนอาคารหรือต้นไม้
  - ความคลาดเคลื่อนรวมกันทำให้ GNSS ที่ไม่ปรับแก้คลาดเคลื่อนราว 5–10 เมตร จึงต้องปรับแก้ก่อนนำไปใช้ในงานสำรวจ

#### 2. GNSS Correction

- **GNSS Correction คืออะไร:** ข้อมูลแก้ค่าที่ส่งให้เครื่องรับ เพื่อหักล้างความคลาดเคลื่อนข้างต้นออกจากพิกัดที่คำนวณได้ [เพิ่มโดย Claude · ที่มา: swiftnav.com · ตัวเลขรอตรวจ]
- **ประกอบด้วยวิธีหลักดังนี้ พร้อมหลักการ** [เพิ่มโดย Claude · ที่มา: swiftnav.com · ตัวเลขรอตรวจ]
  - **DGNSS (Differential GNSS):** เทียบการวัดของเครื่อง Rover กับสถานีอ้างอิงที่ทราบพิกัด แล้วส่งค่าแก้ระยะ (Pseudorange Correction) ของดาวเทียมแต่ละดวง เพื่อกำจัดความคลาดเคลื่อนที่ทั้งสองเครื่องได้รับร่วมกัน ให้ความถูกต้องระดับต่ำกว่า 1 เมตรภายในระยะจำกัด
  - **SBAS (Satellite-Based Augmentation System):** สถานีอ้างอิงภาคพื้นดินคำนวณค่าแก้ แล้วส่งผ่านดาวเทียมค้างฟ้า ครอบคลุมพื้นที่กว้างโดยไม่ต้องมีโครงสร้างพื้นฐานในพื้นที่ ให้ความถูกต้องราว 1–3 เมตร
  - **RTK (Real-Time Kinematic):** ใช้การวัดเฟสคลื่นพาห์ (Carrier Phase) ร่วมกับข้อมูลรหัส แล้วแก้ค่าจำนวนเต็มไม่ทราบค่า (Integer Ambiguity) ด้วยการหาผลต่างสองชั้น (Double Differencing) ให้ความถูกต้องระดับ 1–2 เซนติเมตร ใช้เวลาเริ่มต้นราว 5 วินาที แต่ต้องอยู่ห่างสถานีฐานไม่เกินราว 20–30 กิโลเมตร
  - **PPP (Precise Point Positioning):** ใช้ค่าแก้วงโคจร นาฬิกาดาวเทียม และบรรยากาศ จากสถานีอ้างอิงที่กระจายทั่วโลก ให้ความถูกต้องระดับเซนติเมตรทั่วโลก แต่ต้องรอให้ค่าลู่เข้าราว 10–30 นาที
  - **PPP-RTK:** รวมการครอบคลุมทั่วโลกของ PPP เข้ากับการลู่เข้าเร็วของ RTK โดยส่งค่าแก้แยกเป็นองค์ประกอบ (State Space Representation, SSR) ที่ใช้ได้ทั้งภูมิภาค ให้ความถูกต้องราว 3–7 เซนติเมตร เริ่มต้นราว 10–30 วินาที
- **ที่มา:** https://www.swiftnav.com/resource/blog/what-are-the-different-types-of-gnss-corrections

### Static Survey และการสร้างหมุดควบคุม:

- **Static Survey (การรังวัดแบบสถิต):** เป็นการตั้งเครื่องรับสัญญาณ GNSS ไว้ ณ หมุดรังวัดนิ่งเป็นระยะเวลานาน (ตั้งแต่ 20 นาทีไปจนถึงหลายชั่วโมง)[29] เพื่อบันทึกข้อมูลดิบ (RINEX)[30] แล้วนำไปประมวลผลภายหลัง (Post-Processing) ในสำนักงาน[29]
- **ระดับความแม่นยำและการใช้งาน:** ให้ความถูกต้องสูงที่สุดระดับมิลลิเมตรถึงซับเซนติเมตร (±3–10 มม.)[29][31] จึงเป็นวิธีมาตรฐานสำหรับสร้างและขยายโครงข่าย **หมุดควบคุมหลัก (Control Networks/Benchmarks)**[29][32] งานรังวัดทางธรณีวิทยา งานติดตามการเคลื่อนตัวของโครงสร้าง[33][34] และการรังวัดเชื่อมโยงกับระบบพิกัดหลักของประเทศ[35]
- **หลักการของ Static Survey** [เพิ่มโดย Claude · ที่มา: apeksgnss.com/blog/what-is-static-gnss-survey-explained · ตัวเลขรอตรวจ]
  - เครื่องรับ GNSS ตั้งแต่ 2 เครื่องขึ้นไปสังเกตดาวเทียมชุดเดียวกันพร้อมกันเป็นเวลานาน โดยเครื่องอยู่นิ่ง บันทึกการวัดเฟสคลื่นพาห์ (Carrier Phase) แล้วนำไปประมวลผลภายหลัง ทำให้แก้ค่าจำนวนเต็มไม่ทราบค่า (Integer Ambiguity) ได้เชื่อถือกว่าการแก้แบบเรียลไทม์
  - ขั้นตอน: แปลงไฟล์ดิบเป็น RINEX → ประมวลผลเส้นฐาน (Baseline) ระหว่างจุดที่ตั้งเครื่อง → ปรับแก้โครงข่ายรวมหลายเส้นฐานให้ได้พิกัดและค่าความละเอียดที่สอดคล้องกัน
  - เวลาสังเกตการณ์ขึ้นกับความยาวเส้นฐาน: ไม่เกิน 20 กม. ประมาณ 20–30 นาที, 20–100 กม. ประมาณ 1–4 ชั่วโมง, เกิน 100 กม. ตั้งแต่ 4 ชั่วโมงขึ้นไป
- **ทำไมต้องใช้ Static Survey** [เพิ่มโดย Claude · ที่มา: apeksgnss.com · ตัวเลขรอตรวจ]
  - ให้ความถูกต้องสูงกว่า RTK: Static ประมาณ ±3–10 มม. ทางราบ และ ±5–15 มม. ทางดิ่ง ส่วน RTK ประมาณ ±8–15 มม. ทางราบ เพราะสังเกตนานทำให้แก้ค่า Ambiguity ได้น่าเชื่อถือและเฉลี่ยความคลาดเคลื่อนจากบรรยากาศได้ดีกว่า
  - เหมาะกับงานสร้างโครงข่ายหมุดควบคุม งานควบคุมทางธรณีมาตรและที่ดิน และงานติดตามการทรุดตัวหรือการเคลื่อนตัวของโครงสร้าง ซึ่งความละเอียดระดับ ±3 มม. ตรวจจับการเคลื่อนที่ที่ RTK มองไม่เห็นได้
  - ข้อแลกเปลี่ยน: ต้องประมวลผลภายหลัง ใช้เวลา 20 นาทีถึงหลายชั่วโมงต่อจุด ขณะที่ RTK ได้ผลทันทีและใช้เวลาราว 10–30 วินาทีต่อจุด จึงเหมาะกับงานปักหมุดและสำรวจรายละเอียด

### CORS และระบบอ้างอิงพิกัด:

- **CORS (Continuously Operating Reference Station):** สถานีรับสัญญาณ GNSS ถาวรที่บันทึกข้อมูลตลอด 24 ชั่วโมง[36]
- **เครือข่าย CORS ในประเทศไทย:**
  - **LRTN (กรมที่ดิน):** เครือข่ายสถานีมากกว่า 600 สถานีทั่วประเทศ[28][37] ออกแบบรองรับงานรังวัดที่ดิน ออกโฉนด อ้างอิงระบบพิกัด WGS84 และแปลงเป็น Indian 1975 (UTM)[37][38]
  - **RTSD CORS (กรมแผนที่ทหาร):** เน้นความแม่นยำระดับ Geodetic อ้างอิงระบบพิกัดสากล ITRF / WGS84[37][39] เหมาะสำหรับงานโครงสร้างพื้นฐาน แผนที่ระดับชาติ งานวิชาการ และงานยุทธศาสตร์[39][40]
- **ระบบอ้างอิงพิกัด (Coordinate Reference Systems):** การรังวัดด้วย GNSS ได้ค่าพิกัดบนทรงรีสากล (เช่น WGS84 หรือ ITRF)[41][42] จึงต้องนำมาผ่านกระบวนการแปลงพิกัด (On-site Calibration / Localization) เพื่อให้อยู่ในระบบพิกัดฉากราบท้องถิ่น (เช่น UTM หรือ Indian 1975) และใช้แบบจำลองยีออยด์ (เช่น TGM2017) ในการแปลงความสูงเหนือทรงรี (Ellipsoidal Height) เป็นความสูงออร์โทเมตริกเหนือระดับทะเลปานกลาง (Orthometric Height)[43]

### การประยุกต์ใช้ GNSS ในงานสำรวจภูมิประเทศ:

- **งานรังวัดที่ดินและแบ่งแยกแปลง:** รังวัดขอบเขตและออกโฉนดตามมาตรฐานกรมที่ดินด้วย Network RTK[28][46]
- **งานก่อสร้างและปักหมุดแนว (Construction & Stakeout):** กำหนดแนวเส้นทาง วางผังโครงสร้าง และปักหมุดตำแหน่งอาคาร ถนน สะพาน ได้อย่างรวดเร็ว[32]
- **งานสำรวจรายละเอียดและทำงานร่วมกับโดรน (Drone Survey - RTK/PPK):** ใช้บันทึกตำแหน่งศูนย์กลางภาพถ่ายจากโดรน หรือใช้รังวัดตำแหน่งหมุดควบคุมภาพถ่าย (GCPs) และจุดตรวจสอบ (Checkpoints) ภาคสนามด้วยความแม่นยำระดับเซนติเมตร[48]
- **งานทำระดับด้วย GNSS (GNSS Leveling):** ใช้วิธี Static Survey ร่วมกับแบบจำลองยีออยด์ TGM2017 และสถานี CORS ในการคำนวณหาค่าความสูงออร์โทเมตริกสำหรับงานวิศวกรรมโยธาและงานน้ำ
