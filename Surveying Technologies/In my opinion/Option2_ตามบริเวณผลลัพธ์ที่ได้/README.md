# ทางเลือก 2: แบ่งตามบริเวณผลลัพธ์ที่ได้

สถานะ: ยังไม่มีสไลด์ รอตกลงโครงสร้างก่อน

ข้อตกลงจากการคุยที่ผ่านมา (คำของผู้ใช้สรุปย่อ):
- หน่วยที่นำเสนอคือ "เครื่องมือ" ระดับชนิด และมียี่ห้อสำหรับเปรียบเทียบ; เทคโนโลยี/หลักการเป็นตัวเสริม
- ผู้ฟังตัดสินใจเรื่อง เลือกซื้อ/จ้างเครื่องมือ และเข้าใจว่าที่ผู้สำรวจใช้คืออะไร
- ไม่แบ่งตามที่ตั้งของเครื่อง (เช่น ดาวเทียม) แต่แบ่งตามว่าเอาไปหาอะไรที่ไหน: บริเวณภาคพื้น / ใต้น้ำ / ใต้ผิวดิน (ใต้ผิวดินเป็นหัวข้อของตัวเอง)
- ปิดท้ายด้วยบทการจัดการและวิเคราะห์ข้อมูลเชิงพื้นที่
