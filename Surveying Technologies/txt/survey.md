# เทคโนโลยีการสำรวจภูมิประเทศในปัจจุบัน: จากการรังวัดภาคสนามสู่การสำรวจเชิงดิจิทัล

> ลำดับการเล่าเรื่อง: เทคโนโลยีพื้นฐาน → เทคโนโลยีสมัยใหม่ → การประมวลผล → การประยุกต์ใช้ → แนวโน้มอนาคต

---

## 1. บทนำและความสำคัญของงานสำรวจภูมิประเทศ
- ความสำคัญของข้อมูลภูมิประเทศต่อการออกแบบและก่อสร้าง
- การเปลี่ยนแปลงของเทคโนโลยีงานสำรวจ
- จากการสำรวจแบบดั้งเดิมสู่ Digital Survey

## 2. เทคโนโลยีการกำหนดตำแหน่งด้วยดาวเทียม GNSS
- GNSS, RTK และ Network RTK
- Static Survey และการสร้างหมุดควบคุม
- CORS และระบบอ้างอิงพิกัด
- การประยุกต์ใช้ GNSS ในงานสำรวจภูมิประเทศ

## 3. เทคโนโลยีการสำรวจด้วย Total Station
- การรังวัดมุม ระยะทาง และระดับ
- การสำรวจรายละเอียดภูมิประเทศ
- การทำงานร่วมกับ GNSS และระบบพิกัด

## 4. เทคโนโลยีการสำรวจด้วย UAV/Drone
- Photogrammetry และการถ่ายภาพทางอากาศ
- การวางแผนแนวบินและการกำหนด GCP/Checkpoint
- การสร้าง Orthophoto และ Digital Surface Model
- การประยุกต์ใช้ในพื้นที่ขนาดใหญ่และพื้นที่เข้าถึงยาก

## 5. เทคโนโลยี LiDAR สำหรับการสำรวจภูมิประเทศ
- หลักการทำงานของ LiDAR
- UAV LiDAR และ Mobile/อากาศยาน LiDAR
- Point Cloud และการจำแนกข้อมูล Ground/Non-Ground
- การสร้าง Digital Terrain Model (DTM)

## 6. การสำรวจภูมิประเทศด้วยเทคโนโลยีภาพถ่ายและ Point Cloud
- Photogrammetry กับ LiDAR
- ความแตกต่างด้านความละเอียด ความถูกต้อง และข้อจำกัด
- การเลือกใช้เทคโนโลยีให้เหมาะสมกับลักษณะพื้นที่

## 7. การสำรวจภูมิประเทศทางน้ำและใต้น้ำ
- Echo Sounder และ Multibeam Echo Sounder
- การสำรวจหน้าตัดลำน้ำและท้องน้ำ
- การบูรณาการข้อมูลบนบกและใต้น้ำ
- การประยุกต์ใช้กับงานแม่น้ำ อ่างเก็บน้ำ และโครงการชลประทาน

## 8. การประมวลผลและจัดการข้อมูลสำรวจ
- Point Cloud Processing
- การสร้าง DEM/DTM/DSM
- การสร้าง Contour และ Terrain Model
- การตรวจสอบและประเมินความถูกต้องของข้อมูล

## 9. GIS และการบูรณาการข้อมูลเชิงพื้นที่
- การจัดการข้อมูลสำรวจในระบบ GIS
- การวิเคราะห์ข้อมูลภูมิประเทศ
- การซ้อนทับข้อมูลหลายประเภท
- การจัดทำแผนที่และฐานข้อมูลเชิงพื้นที่

## 10. การบูรณาการข้อมูลสำรวจในรูปแบบ 3D
- 3D Terrain Model
- 3D Point Cloud
- Digital Twin
- การเชื่อมโยงข้อมูลสำรวจกับ BIM/CIM

## 11. ตัวอย่างการประยุกต์ใช้เทคโนโลยีการสำรวจ
- งานสำรวจถนนและโครงสร้างพื้นฐาน
- งานสำรวจแม่น้ำและพื้นที่ริมตลิ่ง
- งานสำรวจพื้นที่ก่อสร้าง
- งานสำรวจพื้นที่เสี่ยงต่อการกัดเซาะ
- งานสำรวจเพื่อการวางแผนและออกแบบ

## 12. แนวโน้มเทคโนโลยีการสำรวจในอนาคต
- AI และ Machine Learning
- Automated Feature Extraction
- Cloud Processing
- Real-time Surveying
- Digital Twin และ Smart Infrastructure
- การพัฒนาไปสู่ Automated/Intelligent Surveying
