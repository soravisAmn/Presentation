# Adjust formatted notes

นำไอเดียที่ผู้ใช้จดไว้ใน `adjust.md` ไปแก้ไฟล์ .md รายบทในโฟลเดอร์ `draft#N\formatted` (ภายใต้ `D:\Yo\Presentation\Presentation\Surveying Technologies`) ผลลัพธ์นี้เป็นอินพุตของสกิล `merge-formatted-into-survey-md`

## ไฟล์ที่เกี่ยวข้อง
- `draft#N\adjust.md` ไอเดียของผู้ใช้ รอบ draft ที่ N ถ้าผู้ใช้ไม่บอกเลข N ให้ใช้โฟลเดอร์ draft ที่เลขมากที่สุดที่มี `adjust.md` และบอกผู้ใช้ว่าใช้เลขไหน
- `draft#N\formatted\*.md` ไฟล์รายบท เป็นไฟล์ที่ถูกแก้
- สร้างโฟลเดอร์ `draft#N\สำรอง\` (ถ้าไม่มี) แล้วใช้เก็บสำเนาก่อนแก้

## รูปแบบ adjust.md
- หัวบทเป็น `## N.` ตามเลขบทใน survey.txt เนื้อหาใต้หัวบทคือคำสั่งหรือข้อความของบทนั้น
- **ข้อความที่อยู่ใน "..." (เครื่องหมายคำพูด)** คือข้อความที่ผู้ใช้ต้องการให้ใส่ลงไฟล์ ให้ใส่ตามถ้อยคำเดิมทุกคำ จัดได้เฉพาะรูปแบบ (หัวข้อ รายการ ย่อหน้า) ตามกติกาของสกิล lossless-note-formatting ห้ามเรียบเรียงใหม่ ห้ามเติมข้อเท็จจริง ตัวเลข หรือเลขอ้างอิง ห้ามเพิ่มข้อความที่ผู้ใช้ไม่ได้ใส่เครื่องหมายคำพูด
- **ข้อความที่ไม่มีเครื่องหมายคำพูด** คือคำสั่ง เช่น แทรกหัวข้อไว้ตรงไหน สลับลำดับหัวข้อ ย้ายหัวข้อ ให้ทำตามคำสั่งนั้น

## ขั้นตอน
1. อ่าน `adjust.md` ทั้งไฟล์ และอ่านไฟล์ `formatted` ของแต่ละบทที่ถูกกล่าวถึงจริงจากดิสก์ ห้ามทำจากความจำ
2. สำรองไฟล์ที่จะแก้ไว้ใน `draft#N\สำรอง\` ก่อนแก้ทุกครั้ง ห้ามเขียนทับสำเนาสำรองเดิม
3. สรุปให้ผู้ใช้ดูสั้นๆ ว่าตีความคำสั่งแต่ละบรรทัดว่าอย่างไร ถ้าคำสั่งใดคลุมเครือ (ไม่แน่ใจว่าแทรกตรงไหนหรือสลับอะไร) ให้ถามก่อนทำเฉพาะข้อนั้น ที่ชัดเจนให้ทำต่อได้เลย
4. แก้ไฟล์ตามคำสั่ง
   - แทรกข้อความหรือหัวข้อตามตำแหน่งที่ระบุ
   - สลับหรือย้ายหัวข้อ แล้วเลขหัวข้อเปลี่ยนตามลำดับใหม่ เช่น ย้าย 2.3 ไปก่อน 2.2 หัวข้อที่ย้ายกลายเป็น 2.2 และหัวข้อเดิมกลายเป็น 2.3 แก้เลขในหัวข้อให้ต่อเนื่องทั้งบท
   - ห้ามลบข้อความใดๆ นอกจากผู้ใช้สั่งลบอย่างชัดเจน
5. ตรวจหลังแก้ว่าข้อความเดิมทุกคำยังอยู่ (เว้นที่ถูกสั่งลบ) และเลขหัวข้อต่อเนื่อง แล้วเขียนไฟล์กลับที่เดิมใน `formatted`
6. รายงานผลสั้นๆ ว่าแก้ไฟล์ใดบ้าง และมีคำสั่งใดที่ไม่ได้ทำเพราะอะไร

## ข้อควรระวัง
- ภาษาไทยเป็นหลัก ศัพท์อังกฤษคงตามเดิม ไม่แก้คำผิดในต้นฉบับเว้นแต่ผู้ใช้สั่ง
- อย่าแตะไฟล์ `survey.txt` และอย่าแก้ `survey.md` สกิลนี้แก้เฉพาะไฟล์ใน `formatted`
- ถ้า `adjust.md` ไม่มีเนื้อหาของบทใด ไม่ต้องแตะไฟล์ของบทนั้น
