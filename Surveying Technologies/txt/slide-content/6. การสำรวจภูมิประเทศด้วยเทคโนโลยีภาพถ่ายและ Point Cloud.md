# บทที่ 6 การสำรวจภูมิประเทศด้วยเทคโนโลยีภาพถ่ายและ Point Cloud

> ร่างเนื้อหาสไลด์ (ยังไม่จัดหน้า) · ตัวเลขทั้งหมดอยู่ในโน้ตผู้บรรยายและรอตรวจแหล่งที่มา

## สไลด์ 6.1 Photogrammetry และ LiDAR ได้ Point Cloud จากหลักการต่างกัน

**ตารางที่ 6.1 เปรียบเทียบหลักการและผลลัพธ์**

| หัวข้อ | Photogrammetry | LiDAR |
|---|---|---|
| หลักการ | สำรวจแบบ Passive Sensing อาศัยแสงธรรมชาติ ถ่ายภาพซ้อนเกยแล้วประมวลผลด้วย SfM และ MVS | สำรวจแบบ Active Sensing ส่งพัลส์เลเซอร์เอง วัดระยะด้วย Time-of-Flight |
| เซนเซอร์ที่ใช้ | กล้องถ่ายภาพ | Laser Scanner, GNSS, IMU |
| ผลลัพธ์หลัก | Orthophoto, 3D Textured Mesh, Point Cloud ที่มีสี RGB | Point Cloud 3 มิติพร้อมค่าความเข้มสัญญาณสะท้อน |
| คุณสมบัติเด่น | ภาพและสีสมจริง | บันทึกสัญญาณสะท้อนหลายครั้ง เจาะผ่านช่องว่างทรงพุ่มไม้ถึงพื้นดิน |

**อ้างอิงต้นทาง:** เลขท้ายประโยคในไฟล์ต้นทาง (ไฟล์นี้เลขอ้างอิงติดกับข้อความ จึงยังไม่คัดลอกมาเพื่อกันอ่านผิด รอรายการแหล่งที่มาจากคุณ)

## สไลด์ 6.2 ความถูกต้องทางดิ่งและเงื่อนไขพื้นที่เป็นตัวแยกสองเทคโนโลยี

- พื้นที่เปิดโล่งที่ใช้ RTK/PPK ร่วมกับ GCP: ความถูกต้องทางราบของทั้งสองเทคโนโลยีใกล้เคียงกัน
- ทางดิ่ง: LiDAR ได้เปรียบด้านความถูกต้องและความสม่ำเสมอ เพราะวัดระยะดิ่งโดยตรง
- Photogrammetry ให้ความถูกต้องทางดิ่งดีในพื้นที่เปิดกว้าง แต่ลดลงมากในพื้นที่ป่าหรือพืชพรรณหนาแน่น
- ความละเอียด: Photogrammetry กำหนดด้วย GSD ส่วน LiDAR กำหนดด้วยความหนาแน่นของจุด (Point Density)

**โน้ตผู้บรรยาย:** ทางราบ Photogrammetry ราว 1–3 ซม. LiDAR ราว 2–5 ซม. · ทางดิ่ง LiDAR ราว 1–3 ซม. (หรือ ±2–15 ซม. สำหรับระบบอากาศยาน) Photogrammetry ราว 2–4 ซม. ในพื้นที่เปิด (รอตรวจแหล่ง)

**อ้างอิงต้นทาง:** เลขท้ายประโยคในไฟล์ต้นทาง (ไฟล์นี้เลขอ้างอิงติดกับข้อความ จึงยังไม่คัดลอกมาเพื่อกันอ่านผิด รอรายการแหล่งที่มาจากคุณ)

## สไลด์ 6.3 ข้อจำกัดเชิงปฏิบัติของแต่ละเทคโนโลยี

**ตารางที่ 6.2 ข้อจำกัดเชิงปฏิบัติ**

| เทคโนโลยี | ข้อจำกัด |
|---|---|
| Photogrammetry | ขึ้นกับแสงธรรมชาติ (ทำงานกลางคืนไม่ได้) · มองไม่ทะลุพืชพรรณ ได้เฉพาะยอดทรงพุ่ม · พื้นผิวไร้ลวดลายหรือสะท้อนแสง (ผิวน้ำ หิมะ ทราย) จับคู่จุดภาพไม่ได้ · ใช้เวลาประมวลผล SfM นาน |
| LiDAR | เซนเซอร์และระบบ GNSS/IMU ราคาสูงกว่ามาก · ข้อมูลดิบไม่มีสี ต้องเพิ่มกล้อง RGB · ต้องใช้ทักษะกรองจุดพื้นดิน (Ground Filtering) |

**โน้ตผู้บรรยาย:** ราคาชุดโดรนในต้นฉบับ: LiDAR $15,000–$350,000+ เทียบ Photogrammetry $2,000–$30,000 (รอตรวจแหล่ง)

**อ้างอิงต้นทาง:** เลขท้ายประโยคในไฟล์ต้นทาง (ไฟล์นี้เลขอ้างอิงติดกับข้อความ จึงยังไม่คัดลอกมาเพื่อกันอ่านผิด รอรายการแหล่งที่มาจากคุณ)

## สไลด์ 6.4 การเลือกเทคโนโลยีพิจารณาจากลักษณะพื้นที่และผลลัพธ์ที่ต้องการ

**ตารางที่ 6.3 แนวทางการเลือกเทคโนโลยี**

| เงื่อนไขของงาน | เทคโนโลยีที่เหมาะสม |
|---|---|
| พื้นที่เปิดโล่ง ไร้สิ่งบดบัง (งานก่อสร้างอาคาร เหมืองเปิด ผังเมือง แปลงเกษตรเปิด) | Photogrammetry |
| ต้องการภาพถ่ายจริง Orthophoto หรือโมเดล 3 มิติที่มีสี | Photogrammetry |
| ต้องควบคุมงบประมาณอุปกรณ์เริ่มต้น | Photogrammetry |
| พื้นที่มีพืชพรรณหรือป่าไม้ปกคลุมหนาแน่น ต้องการ DTM พื้นดินเปล่า | LiDAR |
| ต้องการความถูกต้องทางดิ่งสูง เช่น ดินตัด-ดินถมในภูมิประเทศซับซ้อน อุทกวิทยา/น้ำท่วม | LiDAR |
| แนวระเบียงยาว งานสแกนกลางคืน พื้นที่ต่างระดับซับซ้อน | LiDAR |
| ต้องการทั้งความแม่นยำเรขาคณิตและความสมจริงทางสายตา | ใช้ร่วมกัน (Hybrid Workflow) |

- Hybrid Workflow: ใช้ LiDAR สร้างโครงสร้างเรขาคณิตและระดับความสูง แล้วทาบภาพจาก Photogrammetry เพื่อสร้างแบบจำลอง Digital Twin หรือ BIM

**อ้างอิงต้นทาง:** เลขท้ายประโยคในไฟล์ต้นทาง (ไฟล์นี้เลขอ้างอิงติดกับข้อความ จึงยังไม่คัดลอกมาเพื่อกันอ่านผิด รอรายการแหล่งที่มาจากคุณ)
