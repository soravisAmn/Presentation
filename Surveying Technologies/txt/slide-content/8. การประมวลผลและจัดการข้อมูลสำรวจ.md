# บทที่ 8 การประมวลผลและจัดการข้อมูลสำรวจ

> ร่างเนื้อหาสไลด์ (ยังไม่จัดหน้า)

## สไลด์ 8.1 ขั้นแรกของการประมวลผลคือกรองสัญญาณรบกวนและจำแนกจุดพื้นดิน

- Point Cloud ดิบมีจุดคลาดเคลื่อน (Outliers) ทั้งสูงเกินจริง (เช่น นก อากาศยาน) และต่ำกว่าพื้นดิน ต้องกำจัดในขั้น Preprocessing
- การจำแนกจุด (Ground Filtering / Point Cloud Classification) แยกจุดพื้นดินเปล่า (Ground) ออกจากอาคาร ต้นไม้ พืชพรรณ และยานพาหนะ (Non-Ground)
- จัดเก็บในไฟล์มาตรฐานเปิด .las หรือ .laz ซึ่งบันทึกพิกัด X, Y, Z รหัสประเภทจุด (Class Code) ค่าความเข้ม และสี RGB

**ตารางที่ 8.1 อัลกอริทึมจำแนกจุดพื้นดิน**

| อัลกอริทึม | หลักการ |
|---|---|
| Morphological Filter | ใช้เกณฑ์ความชันและความสูงตัดจุดที่ไม่ใช่พื้นดินออกผ่านโครงสร้างกริด |
| Progressive TIN Densification (PTD) | สร้างโครงข่ายสามเหลี่ยมจากจุดต่ำสุด แล้วเพิ่มจุดพื้นดินตามเกณฑ์มุมและความสูง |
| Cloth Simulation Filter (CSF) | พลิก Point Cloud กลับหัวแล้วทิ้งผ้าจำลองคลุม จุดที่ผ้าสัมผัสคือพื้นดิน |
| Surface / Interpolation-based Filters | ใช้สมการพื้นผิวหรือ Thin Plate Spline (TPS) ประมาณค่าเพื่อคัดเลือกจุดพื้นดิน |

**อ้างอิงต้นทาง:** เลขท้ายประโยคในไฟล์ต้นทาง (เลขอ้างอิงติดกับข้อความ จึงยังไม่คัดลอกมาเพื่อกันอ่านผิด รอรายการแหล่งที่มาจากคุณ)

## สไลด์ 8.2 DEM, DTM และ DSM ต่างกันที่สิ่งที่แบบจำลองรวมไว้

**ตารางที่ 8.2 ประเภทของแบบจำลองความสูง**

| แบบจำลอง | ความหมาย |
|---|---|
| DSM (Digital Surface Model) | รวมวัตถุและโครงสร้างทั้งหมดบนดิน (พื้นดิน อาคาร ต้นไม้) |
| DTM (Digital Terrain Model) | เฉพาะพื้นดินเปล่า (Bare-Earth) หลังผ่าน Ground Filtering |
| DEM (Digital Elevation Model) | คำเรียกกว้างของแบบจำลองความสูงเชิงตัวเลข อาจหมายถึง DTM หรือ DSM ตามบริบท |

- การสร้าง: นำเฉพาะจุดที่จำแนกเป็น Ground (Class 2) มาประมาณค่าเชิงพื้นที่เป็น Regular Grid (Raster)
- วิธีประมาณค่า: Points2Grid (Local Binning), Inverse Distance Weighting (IDW), Kriging, Spline, Triangulation (TIN to Raster)

**อ้างอิงต้นทาง:** เลขท้ายประโยคในไฟล์ต้นทาง (เลขอ้างอิงติดกับข้อความ จึงยังไม่คัดลอกมาเพื่อกันอ่านผิด รอรายการแหล่งที่มาจากคุณ)

## สไลด์ 8.3 โครงสร้าง Grid และ TIN เป็นฐานของเส้นชั้นความสูง

**ตารางที่ 8.3 เปรียบเทียบโครงสร้างแบบจำลองภูมิประเทศ**

| โครงสร้าง | ลักษณะ | จุดเด่น |
|---|---|---|
| Regular Grid / Raster | แบ่งพื้นที่เป็นเซลล์สี่เหลี่ยมขนาดเท่ากัน เก็บค่าความสูงต่อเซลล์ | โครงสร้างเรียบง่าย ประมวลผลรวดเร็ว |
| TIN (Triangulated Irregular Network) | เชื่อมจุดความสูงสุ่มเป็นสามเหลี่ยมไม่ซ้อนทับตามหลัก Delaunay | ปรับความหนาแน่นตามความขรุขระของพื้นที่ |

- เส้นชั้นความสูง (Contour) ลากเชื่อมจุดที่ระดับความสูงเท่ากันจากการประมาณค่าบน TIN หรือ Grid
- แนวเส้นบังคับ (Breaklines) เช่น ขอบถนน คันดิน สันเขา ลำน้ำ ป้องกันไม่ให้สามเหลี่ยมหรือเส้นชั้นความสูงลากข้ามแนวโครงสร้างจริง

**อ้างอิงต้นทาง:** เลขท้ายประโยคในไฟล์ต้นทาง (เลขอ้างอิงติดกับข้อความ จึงยังไม่คัดลอกมาเพื่อกันอ่านผิด รอรายการแหล่งที่มาจากคุณ)

## สไลด์ 8.4 ความถูกต้องของข้อมูลประเมินด้วยจุดตรวจสอบอิสระ

- ความถูกต้องสัมพัทธ์ (Relative Accuracy) คือความแม่นยำภายในโมเดล ความถูกต้องสัมบูรณ์ (Absolute Accuracy) คือความแม่นยำเทียบระบบพิกัดอ้างอิงจริง
- จุดตรวจสอบอิสระ (Independent Checkpoints: CPs) รังวัดด้วยเครื่องมือความถูกต้องสูง (GNSS RTK หรือ Total Station) และไม่นำไปปรับแก้โมเดล
- เปรียบเทียบพิกัด CPs กับค่าจากโมเดลเพื่อประเมินความคลาดเคลื่อนจริง

**ตารางที่ 8.4 ตัวชี้วัดการประเมินความถูกต้อง**

| ตัวชี้วัด | ความหมาย |
|---|---|
| RMSE (Root Mean Square Error) | ตัวชี้วัดหลัก แยกทางราบ (RMSE_xy) และทางดิ่ง (RMSE_z) |
| Mean Error และ S.D. | ค่าคลาดเคลื่อนเฉลี่ยและส่วนเบี่ยงเบนมาตรฐาน |
| Type I / Type II Error | สัดส่วนความผิดพลาดในการจำแนก: จุดพื้นดินถูกจัดผิด / จุดไม่ใช่พื้นดินถูกจัดเป็นพื้นดิน |
| การตรวจสอบเชิงสายตา | ตรวจหาจุดผิดปกติ (Surface Artifacts, Outliers) ในระบบ GIS ก่อนใช้งานจริง |

**อ้างอิงต้นทาง:** เลขท้ายประโยคในไฟล์ต้นทาง (เลขอ้างอิงติดกับข้อความ จึงยังไม่คัดลอกมาเพื่อกันอ่านผิด รอรายการแหล่งที่มาจากคุณ)
