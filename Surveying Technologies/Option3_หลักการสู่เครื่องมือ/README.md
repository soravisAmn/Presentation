# Option 3: วัตถุประสงค์ → หลักการ → เทคโนโลยี → เครื่องมือ

โครงนี้ได้จาก Option 2 หลังปรับตามที่ตกลง
- ภาพรวมงานสำรวจเป็นบทนำสั้น ๆ (1 สไลด์ ~5 นาที) อ้างอิง 6 หน้าที่ของ Option 1
- 4 บท: 1 ตำแหน่งอ้างอิง | 2 การเก็บข้อมูลกายภาพ (2.1 ผิวดิน, 2.2 ใต้น้ำ, 2.3 ใต้ผิวดิน) | 3 ติดตามการเปลี่ยนแปลง | 4 จัดการและวิเคราะห์ข้อมูลเชิงพื้นที่
- ลำดับในแต่ละหัวข้อ: (1) วัตถุประสงค์ (ย่อหน้า) + ตาราง x.1 หลักการ (อธิบายหลักการในตาราง) (2) สไลด์อธิบายเทคโนโลยี เฉพาะเทคโนโลยีที่มีเครื่องมือหลายชนิด (ถ้าเทคโนโลยี = เครื่องมือ ข้ามชั้นนี้) (3) ตาราง x.2 ชนิดเครื่องมือ (คอลัมน์หลักการนำหน้า อธิบายเครื่องมือในตาราง ผลลัพธ์ ความแม่นยำ ข้อจำกัด ต้นทุน) (4) ตาราง x.3 ผลิตภัณฑ์ แยกแถวละ 1 ผลิตภัณฑ์ เว้นคอลัมน์อธิบายและราคาไว้ (ยาวหลายสไลด์) (5) Research trend; ตารางมีชื่อและเลขตามบท (x = เลขบท)
