## 5. เทคโนโลยี LiDAR สำหรับการสำรวจภูมิประเทศ
- หลักการทำงานของ LiDAR
- UAV LiDAR และ Mobile/อากาศยาน LiDAR
- Point Cloud และการจำแนกข้อมูล Ground/Non-Ground
- การสร้าง Digital Terrain Model (DTM)

**5. เทคโนโลยี LiDAR สำหรับการสำรวจภูมิประเทศ**

### 1. หลักการทำงานของ LiDAR
- **ระบบวัดระยะทางแบบ Active Sensing:** LiDAR (Light Detection and Ranging) เป็นระบบสำรวจระยะไกลแบบส่งสัญญาณเอง (Active) โดยยิงพัลส์เลเซอร์ (เช่น คลื่นอินฟราเรดใกล้ / Near Infrared ความยาวคลื่น 1550 นาโนเมตร) ออกไปกระทบวัตถุหรือพื้นผิว แล้วรับสัญญาณสะท้อนกลับมา1more_horiz
- **การวัดระยะทางด้วย Time-of-Flight (ToF):** ตัวรับสัญญาณจะบันทึกระยะเวลาที่พัลส์เลเซอร์ใช้ในการเดินทางไปและกลับ แล้วนำมาคำนวณระยะทางระหว่างเซนเซอร์กับเป้าหมายโดยอาศัยความเร็วแสง1more_horiz
- **องค์ประกอบหลักในการระบุตำแหน่ง 3 มิติ (Sensor Fusion):**
  - **Laser Scanner:** ยิงและรับพัลส์เลเซอร์ พร้อมกระจายลำแสงผ่านกระจกสแกน (Scanning Mirror) ได้นับแสนถึงล้านพัลส์ต่อวินาที4more_horiz
  - **GNSS (DGPS/RTK/PPK):** บันทึกค่าพิกัดตำแหน่งทางภูมิศาสตร์ ($X, Y, Z$) ของตัวเซนเซอร์หรือพาหนะขณะเคลื่อนที่9more_horiz
  - **IMU / IRS (Inertial Measurement Unit):** บันทึกการเปลี่ยนทิศทางและการวางตัวของพาหนะในขณะนั้น ได้แก่ ค่า Roll (เอียงข้าง), Pitch (ก้ม/เงย) และ Heading/Yaw (ทิศทาง)8more_horiz
- **การคำนวณตำแหน่ง 3D:** ระบบจะนำระยะทางที่วัดได้จากเลเซอร์ มารวมกับพิกัด GNSS และมุมการวางตัวจาก IMU เพื่อประมวลผลออกมาเป็นตำแหน่งพิกัดฉาก 3 มิติ ($X, Y, Z$) และค่าความเข้มสัญญาณสะท้อน (Intensity) ของแต่ละจุดกระทบ4more_horiz
- **คุณสมบัติสะท้อนกลับหลายครั้ง (Multiple Returns):** พัลส์เลเซอร์ 1 พัลส์ สามารถสะท้อนกลับได้หลายครั้ง (เช่น First return สะท้อนจากยอดไม้, Intermediate returns สะท้อนจากกิ่งก้าน, และ Last return สะท้อนจากพื้นดิน) ทำให้ LiDAR มีศักยภาพสูงในการเจาะผ่านช่องว่างทรงพุ่มไม้ลงไปวัดระดับพื้นดินจริงใต้ต้นไม้ได้11more_horiz

### 2. UAV LiDAR และ Mobile/อากาศยาน LiDAR

#### Airborne LiDAR (อากาศยาน LiDAR / เครื่องบิน-เฮลิคอปเตอร์):
- ติดตั้งบนเครื่องบินปีกไฟว์หรือเฮลิคอปเตอร์ เหมาะสำหรับการสแกนทำแผนที่ระดับภูมิภาค พื้นที่ขนาดใหญ่มาก หรือแนวระเบียงยาว (Corridor Mapping) เช่น แผนที่ลุ่มน้ำ สายส่งไฟฟ้า ทางหลวง และงานป่าไม้9more_horiz
- ให้ความถูกต้องทางดิ่งสูงระดับ 1–3 เซนติเมตร ถึง 15 เซนติเมตร ขึ้นอยู่กับระดับความสูงบินและสเปกของเซนเซอร์9more_horiz

#### Mobile Terrestrial LiDAR (LiDAR เคลื่อนที่ทางบก - MLS):
- ติดตั้งบนยานพาหนะทางบก (เช่น รถบรรทุกหรือรถ RTV) ทำงานร่วมกับสแกนเนอร์เลเซอร์, GNSS, IMU และ Wheel DMI2122
- เด่นในการเก็บข้อมูลมุมมองเฉียงและด้านข้างที่มีความหนาแน่นจุดสูงมาก เช่น หน้าผาชายฝั่ง ลานทราย คันดิน ผนังอาคาร และถนน2123
- ต้องทำกระบวนการ Boresight Alignment เพื่อปรับแก้ความคลาดเคลื่อนเชิงมุมระหว่างเซนเซอร์ LiDAR กับ IMU ก่อนและหลังการสแกน24more_horiz

#### UAV LiDAR (LiDAR บนโดรน):
- ติดตั้งเซนเซอร์ LiDAR ขนาดเบาบนอากาศยานไร้นักบิน (UAV) เหมาะสำหรับพื้นที่ขนาดเล็กถึงปานกลาง พื้นที่เสี่ยงภัย หรือพื้นที่ป่าไม้4more_horiz
- รวมข้อดีของการบินสแกนทางอากาศที่เจาะผ่านทรงพุ่มไม้ เข้ากับความคล่องตัว ให้ความหนาแน่นจุดสูง (50–200+ จุด/ตร.ม.) และมีค่าใช้จ่ายดำเนินงานต่ำกว่าเครื่องบินขนาดใหญ่18more_horiz

### 3. Point Cloud และการจำแนกข้อมูล Ground/Non-Ground
- **Point Cloud (กลุ่มเมฆจุด 3 มิติ):** กลุ่มข้อมูลพิกัด $X, Y, Z$ มหาศาลที่สะท้อนจากวัตถุและภูมิประเทศ บันทึกคุณลักษณะเพิ่มเติม เช่น ค่าความเข้มสัญญาณ (Intensity), ลำดับการสะท้อน (Return Number) และค่าสี RGB4more_horiz
- **มาตรฐานไฟล์ LAS/LAZ:** เป็นมาตรฐานเปิดสากลที่กำหนดโดย ASPRS ประกอบด้วย Public Header Block, Variable Length Records (VLRs) และ Point Data Records30more_horiz
  - มีการกำหนดรหัสประเภทจุดมาตรฐาน (ASPRS Standard Point Classes) เช่น Class 1: Unclassified, Class 2: Ground, Class 3–5: Low/Medium/High Vegetation, Class 6: Building, Class 7: Low Point (Noise), Class 9: Water3536

#### การจำแนกข้อมูล Ground / Non-Ground (Ground Filtering):
- เป็นกระบวนการคัดแยกพอยต์คลาวด์ออกเป็นกลุ่ม Ground (พื้นดินเปล่า) และ Non-Ground (สิ่งก่อสร้าง อาคาร ต้นไม้ ยานพาหนะ และสัญญาณรบกวน/Noise)37more_horiz
- **หลักการทางกายภาพในการคัดแยก:** อาศัยจุดระดับต่ำสุดในพื้นที่ (Lowest Elevation), เกณฑ์ความชัน (Slope Threshold), ความต่างระดับความสูง (Elevation Difference) และความราบเรียบของพื้นผิว (Smoothness)4041
- **รูปแบบอัลกอริทึมในการจำแนก:**
  - **Progressive TIN Densification (PTD):** สร้างโครงข่ายสามเหลี่ยมระดับหยาบจากจุดต่ำสุด แล้วขยายการคำนวณปรับแก้หาจุดพื้นดินอย่างต่อเนื่อง42
  - **Cloth Simulation Filter (CSF):** จำลองการพลิก Point Cloud กลับหัวแล้วทิ้งผ้าเสมือนลงมาคลุม จุดที่ผ้าสัมผัสจะถูกคัดแยกเป็นพื้นดิน4344
  - **Morphological Filter:** ใช้เกณฑ์ความชันและความสูงในการสกัดจุดออกด้วยโครงสร้างกริด4546

### 4. การสร้าง Digital Terrain Model (DTM)

#### ความแตกต่างระหว่าง DEM, DSM และ DTM:
- **DSM (Digital Surface Model):** แบบจำลองความสูงเชิงพื้นผิวที่รวมวัตถุทั้งหมดบนดิน (พื้นดิน + อาคาร + ต้นไม้) สอดคล้องกับพอยต์คลาวด์ดิบก่อนคัดแยก4748
- **DTM (Digital Terrain Model):** แบบจำลองภูมิประเทศที่แสดงเฉพาะ พื้นดินเปล่า (Bare-Earth) โดยขจัดพืชพรรณและสิ่งก่อสร้างออกหมดแล้ว4748
- **DEM (Digital Elevation Model):** นิยามกว้างๆ ของแบบจำลองความสูงเชิงตัวเลข4748

#### กระบวนการแปลงจุดพอยต์คลาวด์เป็น DTM (Rasterization / Interpolation):
- คัดเลือกเฉพาะจุดพอยต์คลาวด์ที่ได้รับการจำแนกประเภทเป็น Ground (Class 2)49more_horiz
- กำหนดขนาดเซลล์กริด (เช่น 0.5 เมตร) และใช้ Search Radius ในการประมาณค่าเชิงพื้นที่4952
- นำจุดพื้นดินมาประมาณค่าผ่านอัลกอริทึม เช่น Points2Grid (Local Binning) ที่คัดเลือกค่าความสูงต่ำสุดในแต่ละเซลล์กริด หรือใช้ Kriging, IDW และ Triangulation (TIN to Raster)49more_horiz
- ผลลัพธ์ DTM แบบ Regular Grid หรือ TIN จะถูกนำไปใช้คำนวณปริมาณงานดินตัด-ดินถม (Cut & Fill Volume), งานวิเคราะห์ทางอุทกวิทยา และการเขียนเส้นชั้นความสูง (Contour Lines) ในระบบ CADD/GIS ต่อไป
