หัวข้อการบรรยาย
“เทคโนโลยีการสำรวจภูมิประเทศในปัจจุบัน: จากการรังวัดภาคสนามสู่การสำรวจเชิงดิจิทัล”
1.	บทนำและความสำคัญของงานสำรวจภูมิประเทศ 
o	ความสำคัญของข้อมูลภูมิประเทศต่อการออกแบบและก่อสร้าง 
o	การเปลี่ยนแปลงของเทคโนโลยีงานสำรวจ 
o	จากการสำรวจแบบดั้งเดิมสู่ Digital Survey 
2.	เทคโนโลยีการกำหนดตำแหน่งด้วยดาวเทียม GNSS 
o	GNSS, RTK และ Network RTK 
o	Static Survey และการสร้างหมุดควบคุม 
o	CORS และระบบอ้างอิงพิกัด 
o	การประยุกต์ใช้ GNSS ในงานสำรวจภูมิประเทศ 
3.	เทคโนโลยีการสำรวจด้วย Total Station 
o	การรังวัดมุม ระยะทาง และระดับ 
o	การสำรวจรายละเอียดภูมิประเทศ 
o	การทำงานร่วมกับ GNSS และระบบพิกัด 
4.	เทคโนโลยีการสำรวจด้วย UAV/Drone 
o	Photogrammetry และการถ่ายภาพทางอากาศ 
o	การวางแผนแนวบินและการกำหนด GCP/Checkpoint 
o	การสร้าง Orthophoto และ Digital Surface Model 
o	การประยุกต์ใช้ในพื้นที่ขนาดใหญ่และพื้นที่เข้าถึงยาก 
5.	เทคโนโลยี LiDAR สำหรับการสำรวจภูมิประเทศ 
o	หลักการทำงานของ LiDAR 
o	UAV LiDAR และ Mobile/อากาศยาน LiDAR 
o	Point Cloud และการจำแนกข้อมูล Ground/Non-Ground 
o	การสร้าง Digital Terrain Model (DTM) 
6.	การสำรวจภูมิประเทศด้วยเทคโนโลยีภาพถ่ายและ Point Cloud 
o	Photogrammetry กับ LiDAR 
o	ความแตกต่างด้านความละเอียด ความถูกต้อง และข้อจำกัด 
o	การเลือกใช้เทคโนโลยีให้เหมาะสมกับลักษณะพื้นที่ 
7.	การสำรวจภูมิประเทศทางน้ำและใต้น้ำ 
o	Echo Sounder และ Multibeam Echo Sounder 
o	การสำรวจหน้าตัดลำน้ำและท้องน้ำ 
o	การบูรณาการข้อมูลบนบกและใต้น้ำ 
o	การประยุกต์ใช้กับงานแม่น้ำ อ่างเก็บน้ำ และโครงการชลประทาน 
8.	การประมวลผลและจัดการข้อมูลสำรวจ 
o	Point Cloud Processing 
o	การสร้าง DEM/DTM/DSM 
o	การสร้าง Contour และ Terrain Model 
o	การตรวจสอบและประเมินความถูกต้องของข้อมูล 
9.	GIS และการบูรณาการข้อมูลเชิงพื้นที่ 
o	การจัดการข้อมูลสำรวจในระบบ GIS 
o	การวิเคราะห์ข้อมูลภูมิประเทศ 
o	การซ้อนทับข้อมูลหลายประเภท 
o	การจัดทำแผนที่และฐานข้อมูลเชิงพื้นที่ 
10.	การบูรณาการข้อมูลสำรวจในรูปแบบ 3D 
o	3D Terrain Model 
o	3D Point Cloud 
o	Digital Twin 
o	การเชื่อมโยงข้อมูลสำรวจกับ BIM/CIM 
11.	ตัวอย่างการประยุกต์ใช้เทคโนโลยีการสำรวจ 
o	งานสำรวจถนนและโครงสร้างพื้นฐาน 
o	งานสำรวจแม่น้ำและพื้นที่ริมตลิ่ง 
o	งานสำรวจพื้นที่ก่อสร้าง 
o	งานสำรวจพื้นที่เสี่ยงต่อการกัดเซาะ 
o	งานสำรวจเพื่อการวางแผนและออกแบบ 
12.	แนวโน้มเทคโนโลยีการสำรวจในอนาคต 
o	AI และ Machine Learning 
o	Automated Feature Extraction 
o	Cloud Processing 
o	Real-time Surveying 
o	Digital Twin และ Smart Infrastructure 
o	การพัฒนาไปสู่ Automated/Intelligent Surveying
